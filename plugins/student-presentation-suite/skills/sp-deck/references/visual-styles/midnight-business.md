# Midnight Business（深蓝商务）

- **Style character:** Executive, polished, decisive, and suited to strategy, management, and business cases.
- **Palette:** canvas `F6F8FC`; surface `FFFFFF`; primary text `17213C`; secondary text `52627A`; primary accent `3157A4`; secondary accent `3B82F6`.
- **Background reference:** Cover uses a primary-text midnight field with canvas-colored title; content uses a light canvas; section alternates dark and light only when useful; closing returns to midnight.
- **SVG reference:** `midnight-beam` — Optional beam motif on the cover, a section page, or the closing; never place it behind body copy. This is optional guidance, never an automatic decoration quota.
