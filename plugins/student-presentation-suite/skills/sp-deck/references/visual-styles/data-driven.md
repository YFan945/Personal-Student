# Data Driven（数据驱动）

- **Style character:** Analytical, chart-conscious, precise, and focused on traceable quantitative findings.
- **Palette:** canvas `F8FAFC`; surface `FFFFFF`; primary text `111827`; secondary text `4B5563`; primary accent `2563EB`; secondary accent `16A34A`.
- **Background reference:** Cover uses a clean canvas or primary-text field with one data cue; content stays neutral so charts dominate; section may use a sparse coordinate cue; closing returns to the cover treatment.
- **SVG reference:** `data-axis` — Optional axis, bracket, or data-point motif; never use it as a substitute for an actual chart. This is optional guidance, never an automatic decoration quota.
