# Academic Rigorous（学术严谨）

- **Style character:** Formal, evidence-first, restrained, and suitable for teacher-scored academic work.
- **Palette:** canvas `F8FAFC`; surface `FFFFFF`; primary text `0F172A`; secondary text `475569`; primary accent `1D4ED8`; secondary accent `8B9BAB`.
- **Background reference:** Cover may use a primary-text navy field or quiet canvas; content uses canvas with white surfaces only for meaningful grouping; section uses canvas or navy with one restrained cue; closing echoes the cover.
- **SVG reference:** `academic-bracket` — Optional bracket or evidence-rail motif on the cover, a section page, or one representative evidence page. This is optional guidance, never an automatic decoration quota.
