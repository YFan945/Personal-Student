# Modern Minimal（现代简洁）

- **Style character:** Clean, spacious, direct, and centered on one strong visual or message at a time.
- **Palette:** canvas `F8FAFC`; surface `FFFFFF`; primary text `111827`; secondary text `6B7280`; primary accent `2563EB`; secondary accent `93C5FD`.
- **Background reference:** Cover uses open canvas with one focal accent or an optional dark field; content remains mostly unboxed; section uses one focal cue; closing echoes the minimal cover.
- **SVG reference:** `minimal-focus` — Optional focal-dot or alignment motif used sparingly at structural moments. This is optional guidance, never an automatic decoration quota.
