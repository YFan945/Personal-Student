# Cherry Bold（樱桃醒目）

- **Style character:** Bold, persuasive, high-contrast, and reserved for strong priorities, risks, or conclusions.
- **Palette:** canvas `FCF6F5`; surface `FFFFFF`; primary text `182033`; secondary text `5B6475`; primary accent `990011`; secondary accent `2F3C7E`.
- **Background reference:** Cover uses a cherry or navy statement field; content uses warm off-white and evidence-backed red emphasis; section chooses cherry or navy; closing returns to the strongest cover color.
- **SVG reference:** `cherry-slash` — Optional slash or directional motif for a decisive cover, comparison, or conclusion. This is optional guidance, never an automatic decoration quota.
