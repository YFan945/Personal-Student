# Charcoal Editorial（炭黑杂志）

- **Style character:** Editorial, typographic, monochrome-leaning, and deliberately asymmetric.
- **Palette:** canvas `F2F2F2`; surface `FFFFFF`; primary text `111111`; secondary text `4B5563`; primary accent `36454F`; secondary accent `C9B89B`.
- **Background reference:** Cover uses charcoal or off-white with strong type hierarchy; content uses flat image/text regions; section may use restrained crop marks; closing repeats the cover contrast.
- **SVG reference:** `editorial-crop` — Optional crop-mark motif for the cover, a section page, or an image-led editorial page. This is optional guidance, never an automatic decoration quota.
